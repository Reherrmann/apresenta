# apresenta

Gerador de apresentações da Pluri. A página lê uma planilha Excel (.xlsx), mostra um painel de gráficos e gera a apresentação em PowerPoint ou PDF. Tudo roda no navegador; nenhum dado é enviado a servidor.

- Publicação: `www.pluri.app.br/apresenta`
- Planilha-modelo (dados fictícios): `base-ficticia-instituto-alvorada-2025.xlsx`
- Abas esperadas: Projetos, Projeto_Equipe, Frentes, Parceiros, Equipe, Producao_Eventos
- Bibliotecas em `vendor/`: SheetJS 0.18.5, PptxGenJS 3.12.0, Chart.js 4.4.1

Todos os dados deste repositório são fictícios.
